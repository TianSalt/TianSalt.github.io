# 1.3 A Discrete Probability Toolbox

Why probability in a cryptography course? Because over the decades, constructions that *looked* secure were found broken, and the repairs were not more cleverness but **precise definitions of what secrecy means**. Every definition we will use — perfect security, pseudorandomness, unforgeability — quantifies over *events* like “the attacker outputs the right key” and bounds their *probabilities*. This crash course collects the tools the rest of the tutorial needs: distributions, events, the union bound, random variables, independence, one lemma about XOR, and the birthday paradox. (The lectures point to the Wikibooks *discrete probability* primer as background; everything essential is developed below.)

Throughout, $U$ is a **finite** set — typically $U = \{0,1\}^n$, the set of bit strings of length $n$, written $\{0,1\}^n$ for short.

## 1.3.1 Probability distributions

::: theorem Definition (probability distribution)
A **probability distribution** $P$ over a finite set $U$ is a function $P : U \to [0,1]$ such that

$$\sum_{x \in U} P(x) = 1 .$$
:::

Two extremes matter:

- **Uniform distribution:** $P(x) = 1/|U|$ for every $x \in U$.
- **Point distribution at $x_0$:** $P(x_0) = 1$ and $P(x) = 0$ for all $x \neq x_0$.

A distribution is nothing mysterious — for $U = \{0,1\}^3$ it is exactly the vector

$$\bigl(P(000),\, P(001),\, P(010),\, \dots,\, P(111)\bigr) \in [0,1]^8$$

whose entries sum to $1$. The uniform distribution on $\{0,1\}^3$ is the all-eighths vector; the point distribution at $101$ is $(0,0,0,0,0,1,0,0)$.

::: details Quiz (from the lecture): can a distribution over $U$ put probability more than $\tfrac12$ on *some* element, or exactly none?
Both directions are possible, but size constrains them: if $|U| \ge 2$, no rule forces some element to carry probability $> 1/2$ (uniform is a counterexample), and a point distribution concentrates *everything* on one element. What *is* true and used constantly: if a distribution gives **every** element probability at most $1/|U|$ …then it must be uniform. Equality questions like this are why we keep the vector picture in mind.
:::

## 1.3.2 Events and the union bound

For a subset $A \subseteq U$, define

$$\Pr_{x \leftarrow P}[A] := \sum_{x \in A} P(x),$$

and call $A$ an **event**. Necessarily $\Pr[U] = 1$.

Example: on $U = \{0,1\}^8$ with the uniform distribution, the event

$$A = \{\, x \in U : \text{the last two bits of } x \text{ are } 11 \,\}$$

has probability $1/4$ (a quarter of all strings end in `11`).

The one inequality you will use in every security proof:

::: theorem Theorem (union bound)
For events $A_1$ and $A_2$,

$$\Pr[A_1 \lor A_2] \le \Pr[A_1] + \Pr[A_2].$$
:::

The proof is one line: $\Pr[A_1 \lor A_2]$ sums $P(x)$ over $A_1 \cup A_2 \subseteq$ (the multiset sum) $A_1 + A_2$, which counts overlaps twice. Induction extends it to finitely many events. In cryptography its work is always the same: “the attack fails only if *one of* the bad events $A_1, \dots, A_q$ happens; each has probability $\le \epsilon$; so the whole experiment fails with probability $\le q\epsilon$.” Controlling a union of many small events is the bread and butter of reduction proofs.

Example from the slides: on $U = \{0,1\}^n$ uniform, let $A_1$ be “the last two bits are 11” and $A_2$ be “the first two bits are 11”. Each has probability $1/4$, so

$$\Pr[A_1 \lor A_2] \le \tfrac14 + \tfrac14 = \tfrac12 .$$

(Here the true value is $7/16$: the bound costs almost nothing and the slack is fine for proofs.)

## 1.3.3 Random variables

::: theorem Definition (random variable)
A **random variable** $X$ (over $U$, taking values in $V$) is a function $X : U \to V$.
:::

$X$ does not have its own distribution; it *induces* one on $V$:

$$\Pr[X = v] := \Pr\bigl[X^{-1}(v)\bigr] = \sum_{x \,:\, X(x) = v} P(x).$$

Example: $X : \{0,1\}^n \to \{0,1\}$ defined by $X(y) = \mathrm{lsb}(y)$, the last bit. Under the uniform distribution on $\{0,1\}^n$, exactly half the strings end in $0$ and half in $1$, so

$$\Pr[X = 0] = \Pr[X = 1] = \tfrac12 .$$

The picture that keeps this straight: $U$ is the sample space with its distribution $P$; $X$ partitions $U$ into fibers $X^{-1}(v)$; the probability of $v$ is the total mass of its fiber.

::: details Quiz (from the lecture): let $r$ be uniform on $\{0,1\}^2 = \{00, 01, 10, 11\}$ and define $X$ to be the number of 1-bits of $r$. Find $\Pr[X = 2]$.
$X = 2$ happens only for $r = 11$, so $\Pr[X = 2] = \Pr[r = 11] = 1/4$. Likewise $\Pr[X=1] = 1/2$ and $\Pr[X=0] = 1/4$: $X$’s distribution on $V = \{0,1,2\}$ is *not* uniform even though $r$ is. Random variables reshape the distribution they inherit — never confuse “uniform on $U$” with “uniform on $V$”.
:::

## 1.3.4 The uniform random variable and sampling notation

To say “we draw an element of $U$ uniformly at random” the course writes

$$ r \xleftarrow{\mathrm{R}} U, $$

meaning: $r$ is the uniform random variable on $U$, i.e. the random variable satisfying, for all $a \in U$,

$$\Pr[r = a] = \frac{1}{|U|} .$$

Formally $r$ is just the identity function $r(x) = x$ on the set $U$ *equipped with the uniform distribution*. (The arrow-with-R notation is the book’s, not the lecturer’s; it appears throughout modern crypto papers.) This notation will do heavy lifting later: $k \xleftarrow{\mathrm{R}} \mathcal{K}$ for picking a key, $c \leftarrow E(k, m)$ for computing a ciphertext, and adversaries sampled like everything else.

## 1.3.5 Independence

::: theorem Definition (independence)
Events $A, B$ are **independent** if

$$\Pr[A \land B] = \Pr[A] \cdot \Pr[B].$$

Random variables $X, Y$ (taking values in $V$) are **independent** if for all $a, b \in V$,

$$\Pr[X = a \land Y = b] = \Pr[X = a] \cdot \Pr[Y = b].$$
:::

Example: $r$ uniform on $\{0,1\}^2$; $X = \mathrm{lsb}(r)$, $Y = \mathrm{msb}(r)$. Then

$$\Pr[X = 0 \land Y = 0] = \Pr[r = 00] = \tfrac14 = \tfrac12 \cdot \tfrac12 = \Pr[X=0]\Pr[Y=0],$$

and the same check for the other seven pairs, so $X$ and $Y$ are independent. Independence is not automatic — two functions of a uniform variable can be wildly correlated ($\mathrm{lsb}(r)$ and “$\mathrm{lsb}(r) = \mathrm{msb}(r) \oplus 1$” are perfectly *anti*-correlated) — so in proofs it must be either *checked* or *assumed*, and this course will make “independent” appear in hypotheses more than once. The crucial instance arrives with XOR.

## 1.3.6 Randomized algorithms

A **deterministic** algorithm takes an input $m$ and produces $y \leftarrow A(m)$. A **randomized** algorithm also reads fresh random coins:

$$y \leftarrow A(m; r), \qquad r \xleftarrow{\mathrm{R}} \{0,1\}^n,$$

and its *output is a random variable* — run the algorithm twice on the same input, get (possibly) different outputs. The slide’s example is already familiar: encryption *is* a randomized algorithm in disguise, $A(m; k) = E(k, m)$ — the key plays the role of the coins. From Chapter 3 onward, “attacker” will always mean a randomized algorithm, and security definitions quantify over the randomness of both the scheme and the adversary. This is why all of the probability above was necessary: a claim like “the attacker wins with probability at most $2^{-100}$” has no meaning until you say *over which coins*.

## 1.3.7 XOR: one lemma to rule them all

The bitwise **XOR** of two strings in $\{0,1\}^n$ is their bit-by-bit addition mod 2:

$$
\begin{array}{rrrrrrr}
0&1&1&0&1&1&1\\
\oplus\quad 1&0&1&1&0&1&0\\ \hline
1&1&0&1&1&0&1
\end{array}
$$

XOR has the algebraic shape the course needs: for every fixed $s$, the map $x \mapsto x \oplus s$ is a **bijection** of $\{0,1\}^n$ onto itself (its own inverse). The single most useful lemma in the first half of the course:

::: theorem Theorem (masking lemma)
Let $Y$ be any random variable over $\{0,1\}^n$, let $X$ be **uniform** on $\{0,1\}^n$, and let $X$ and $Y$ be **independent**. Then

$$Z := Y \oplus X$$

is uniform on $\{0,1\}^n$, whatever $Y$ is.
:::

Proof (from the lecture, $n$ bits; the slides sketch $n=1$): fix any $a \in \{0,1\}^n$. Partition the event “$Z = a$” according to the value $y$ that $Y$ took:

$$\Pr[Z = a] = \sum_{y \in \{0,1\}^n} \Pr[Y = y \land X = a \oplus y] = \sum_{y} \Pr[Y = y] \cdot \Pr\bigl[X = a \oplus y\bigr],$$

where the second equality is independence. But $X$ is uniform, so $\Pr[X = a \oplus y] = 2^{-n}$ for *every* $y$:

$$\Pr[Z = a] = \sum_y \Pr[Y = y] \cdot 2^{-n} = 2^{-n} \sum_y \Pr[Y = y] = 2^{-n} \cdot 1 = 2^{-n} .$$

Since $a$ was arbitrary, $Z$ is uniform. ∎

Read the theorem one way and it is a fact about distributions. Read it the way the course uses it, it is *a security statement*: let $Y$ be a message and $X$ a fresh uniform key — then the ciphertext $Y \oplus X$ is uniform, meaning **the ciphertext is independent of the message**: an eavesdropper sees a string that is literally indistinguishable from coin flips. That is the one-time pad, and this lemma is nearly the whole proof (the rest is making “sees nothing” precise). Keep $X$ fixed and reuse it for many messages, and the lemma silently dies — which is the one-time-pad-versus-Vigenère lesson of Section 1.2 in a single line of algebra.

## 1.3.8 The birthday paradox

::: theorem Theorem (birthday bound)
Let $r_1, \dots, r_n$ be independent, identically distributed random variables, each uniform on a finite set $U$. When

$$n \approx 1.2 \cdot |U|^{1/2},$$

the probability that *some pair collides*, $\Pr[\exists\, i \neq j : r_i = r_j]$, exceeds $\tfrac12$.
:::

Derivation, following the lecture: assume (as the proof does) the samples are independent; work with the complement. “No collision” means $r_2 \notin \{r_1\}$, $r_3 \notin \{r_1, r_2\}$, and so on, so

$$\Pr[\text{no collision}] = 1 \cdot \left(1 - \frac{1}{|U|}\right) \cdot \left(1 - \frac{2}{|U|}\right) \cdots \left(1 - \frac{n-1}{|U|}\right).$$

With $e^{-x} \ge 1 - x$ applied term by term,

$$\Pr[\text{no collision}] \le \exp\!\left( -\,\frac{1 + 2 + \cdots + (n-1)}{|U|} \right) = \exp\!\left( -\frac{n(n-1)}{2|U|} \right),$$

so

$$\Pr[\text{collision}] \;\ge\; 1 - e^{-n^2 / (2|U|)}$$

up to the harmless $n$ versus $n-1$ bookkeeping. Now set $n = 1.2\,|U|^{1/2}$: the exponent is $n^2/(2|U|) = 1.44/2 = 0.72$, and $1 - e^{-0.72} \approx 0.51 > \tfrac12$. ∎ (The bound holds precisely for the uniform distribution; for non-uniform distributions collisions are only *more* likely, and the exact constant does not matter for us.)

Why it is called a “paradox”: with $U = \{1, \dots, 365\}$ (birthdays), the threshold is $1.2\sqrt{365} \approx 23$ — **only 23 people in a room make a shared birthday more likely than not**, which feels absurd. The intuition is that “$n$ people” hides $\binom{n}{2} \approx n^2/2$ *pairs*, and it is the pairs, not the people, that collide. The square root is the whole story: collision risk grows like $n^2/|U|$, so a $|U|$-sized space offers only $\sqrt{|U|}$ bits of collision work.

The lecture’s worked table plugs in $|U| = 10^6$:

| $n$ (samples) | collision probability $\approx 1 - e^{-n^2/2\cdot10^{-6}}$ |
|---|---|
| $1{,}000$ | $0.39$ |
| $1{,}200$ | $0.51$ |
| $1{,}600$ | $0.73$ |
| $2{,}100$ | $0.89$ |

and the cryptographic instantiation appears one chapter from now: take $U = \{0,1\}^{128}$. After sampling about $2^{64}$ random messages, *some two will likely coincide* — $128$ “bits” of security collapse to $64$ against anything that hunts for collisions. When Chapter 8 (collision-resistant hashing) meets MD5’s 128-bit outputs, the birthday bound is the reason a $2^{64}$-time attack was always on the menu, and every hash size discussed in this course will be judged by it.

## 1.3.9 Summary

| Tool | Statement | Where it will pay off |
|---|---|---|
| Distribution | $P: U \to [0,1]$, $\sum P = 1$ | keys, coins, outputs are all distributions |
| Union bound | $\Pr[\bigvee_i A_i] \le \sum_i \Pr[A_i]$ | every reduction proof’s “bad event” accounting |
| Random variable | $X: U \to V$, $\Pr[X=v] = \Pr[X^{-1}(v)]$ | adversaries’ views, outputs, guesses |
| Sampling | $r \xleftarrow{\mathrm{R}} U$ | notation of all definitions |
| Independence | $\Pr[X{=}a \land Y{=}b] = \Pr[X{=}a]\Pr[Y{=}b]$ | hypothesis of the masking lemma |
| Masking | $Y \oplus X$ uniform if $X$ uniform and independent of $Y$ | **perfect security of the one-time pad** |
| Birthday | collision likely at $n \approx 1.2\sqrt{|U|}$ | hash collisions, key search ($2^{56}$ DES: trivial) |

With the notation settled, Chapter 2 can ask the real question: what *is* a secure cipher, precisely? — and answer it, for the first and last time in perfect terms, with the one-time pad.
